# 文体选择与准确性质检

文体决定词汇、句法和修辞处理方式；所有文体共同遵守源文忠实性。Pinkham 的诊断方法可帮助识别冗余和结构问题，但每条建议都须在具体上下文中判断，不能作为自动删词规则。短文本直接完成必要核查，只有文体取舍或证据缺口影响用户判断时才说明。

## 小节 A — 文体与检查重点

| 文体 | 检查重点 |
|---|---|
| **政论/外宣/公文** | 保留政策范围、力度、目标与讲话风格。与本处概念相符的官方定译优先；套语中的努力、承诺与优先级不能随表达简化而丢失。例如防汛抗旱用 flood control and drought relief。 |
| **技术文档** | 术语固化优先于拆名词串，按同一概念保持一致；含混的主体或因果不能靠常识补齐，必要时向作者核实。 |
| **学术论文** | 保留情态、限定、证据范围和统计表述。show、demonstrate、verify、confirm、prove 依具体含义选择，不按固定强弱阶梯替换；不把普通概念自动升格为特定范式术语。被动语态按目标期刊和上下文判断。 |
| **商务信函** | 寒暄、缓冲和礼貌承载关系信息。保留请求、建议、拒绝与承诺的区别，不能一概当作空话删去。 |
| **企业外宣/官网** | 忠实呈现排名、自我评价、承诺及限定。原文主张有疑点时可另作核实提示；降低宣称强度、改写收益承诺或调整定位须有用户授权，并与忠实译文区分。 |
| **口语/演讲稿** | 主干清晰、便于听懂，适度重复可保留。说话人的迟疑、强调和个人语气属于信息，不强制句末焦点。 |
| **文学/散文** | 保留排比、复沓、意象与有意延迟揭示的作用。删繁建议逐例判断；现成英语习语不能自动替换原文意象。 |
| **混合文本** | 新闻、采访和行业文章按段落功能选择检查。技术细节、例子、受访者归属、标题与图注分别对照，不能跨发言者移接信息。 |

读者背景影响用词和解释密度。面向不同英语使用者时，一致、清楚的表达常比生僻习语更有用；补充解释应与源文陈述区分。

## 小节 B — 边界红线

1. **删词前确认等值**：被删成分确实没有独立意义，或其意义已被译文其他成分完整表达。原文的尝试、意愿、程度与限定在所有文体中保留。
2. **修饰语按功能处理**：事实限定、近似、不确定性、自谦、强调和修辞均可能有意义，频率不是删除依据；替换成更强的词同样可能失真。
3. **并列项分别核义**：经验与教训、权利与利益、制定与实施等不自动合并；存疑时保留两项。
4. **补词须有依据**：补主语、连接词或结构成分前，核对源文及上下文。无从确定时选被动、非人称或较开放表达，不补造施事、因果或具体事实。
5. **引文保真**：源文已有的英文引语和正式名称照录；中文引语翻译时保留其内容、归属与语气，不以润色名义摘要。权威译本与自行翻译应区分。
6. **改后回查**：局部改写后重读对应原段及相关指代，确认未引入新的遗漏、增译或逻辑变化。

## 小节 C — 准确性质检清单

1. **原文到译文的覆盖**：主张、动作、例子、列举、限定、标题、图注与署名逐项有对应，不能仅靠段落数相同认定完整。
2. **译文到原文的依据**：每个事实性陈述、补出的角色和逻辑关系有源文或上下文支持。外部知识可消歧，不补写成作者的陈述。
3. **情态与范围**：分别检查尝试与结果、目标与事实、可能与确定、近似与精确、部分与全部、逐一与集合、否定及条件。必要条件不能变成充分条件。
4. **逻辑关系**：时间先后不等于因果，并列不等于选择；某一对象的两个动作互斥，不代表多个对象不能分别进行这些动作。
5. **主体与归属**：补出的主语有依据，跨段、话题和发言者变化时重新核对；正文、图注和不同受访者的事实不移接。
6. **专名、数字、单位、日期**：逐项核对，保留时间参照点和尺度，不能补入未说明的型号、国别、标度或机构。
7. **搭配与术语**：不确定的搭配查证。相同概念保持一致，不同概念不因词形接近而合并；具体构式允许自然的词形变化。
8. **英文表达**：检查修饰语附着、平行、指代、时态和语域；singular they、while 的对比义和合法英文弯引号不能机械判错。
9. **修辞与语气**：强调、比喻、重复和个人语气的作用保留，企业宣称与正式承诺不擅自降格或升格。
10. **长文合并**：分段核查后检查全篇顺序、缺段、术语、指代、链接和附件；脚本只能组装已核查内容。修复后复查受影响部分。

不设压缩率或零警告目标。长度、格式、脚本通过和模型自述都不能证明语义合格。质量案例与评估方式见根目录 `test-prompts.json`；触发测试、机械扫描与翻译质量分别验收。
